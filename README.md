# genai-interview-questions

I’ve built the 40-question page in your navy, gold and teal style, with the light theme as default and a dark-mode toggle. 
Every question has at least two worked examples (82 in total), and I’ve also zipped up the runnable code samples.

What each question card has:

what the question is really testing
a short answer you can say in about 30 seconds
a detailed explanation
the worked examples
what interviewers listen for, a red-flag answer to avoid, and a likely follow-up question (the six rapid-fire ones at the end skip the follow-up)
